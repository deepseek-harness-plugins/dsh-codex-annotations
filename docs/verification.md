14 项数据与状态测试覆盖：空评论、Unicode/多行/定界符往返、大选区和长评论不截断、普通文字不被误当作协议、刷新恢复与最小空缺编号复用、保留其他及已发送批注编号、迟到确认不误清除复用编号的新批注、批量移除保留已发送记录并使旧引用失效、会话隔离、仅确认已接受的原始批次、发送中编辑不被旧确认清除、勾选行为、存储失败不发布假状态、歧义原文不猜测定位。

## 0.2.9 已发送消息布局

已发送批注入口位于原生消息内容上方，右对齐、圆角胶囊，间距 8px；原生消息操作栏保留在下方。仅包含批注的消息同样保留原生操作栏。实现只调整插件自己的渲染顺序和样式，不读取或修改任何第三方插件的选择器、状态或按钮。

真实宿主验证正文消息、仅批注消息与刷新后的顺序；`sent-message-layout.json/png` 和 `annotation-only-message-layout.json/png` 记录位置及截图，确认原生操作栏位于最后，批注按钮位于消息内容之前。

## 0.2.8 模型输入精简

宿主通过公共 `Session.deriveMessages()` 与 `Session.deriveEventMessage()` 返回模型专用副本，覆盖对话和历史压缩请求，仅转换用户消息中的完整合法批注块。会话事件、原始历史缓存与客户端回显保留完整数据；停用插件恢复原方法。模型仅收到编号、完整原文和非空评论，不发送 UUID、会话标识、前后缀、区间或版本号；不截断原文和评论。旧版 V1 批注继续可读。

新增验证覆盖冻结消息无修改、其他角色和附件不变、破损协议原样保留、多批次顺序、已打开与新会话、真实宿主停用与再次启用、历史批注自动精简，以及原生 `/compact` 的实际模型请求。旧样例 5 条批注从 1963 个 UTF-16 字符减为 538 个，减少 72.59%；这是字符数而非模型 tokenizer 的 token 实测。

## 证据与复现

运行 `npm run test:host` 后，`artifacts/verification.json` 记录检查列表和实际用户消息，`artifacts/model-request.json` 记录模型收到的完整消息，`artifacts/host.log` 记录隔离测试宿主启动结果。截图位于同一目录。新增 `artifacts/ui-measurements.json` 记录真实控件的尺寸、位置、圆角、字体、主题色和阴影；`pixel-*@2x.png` 保留 Chrome DPR=2 的实际控件截图。原始证据保持完整；目录不进入 Git 或安装包。

`artifacts/compaction-model-request.json` 保留原生历史压缩的实际模型输入，可核对批注原文和评论完整、定位字段未发送。

`linked-highlight-after.json` 与 `linked-highlight-after@2x.png` 记录含两个 GitHub 链接、行内代码和加粗文本的选区，以及背景像素采样和原生链接命中结果。设置 `DCA_LINK_CAPTURE=before` 可跳过颜色一致性断言，采集旧实现的对照；旧版链接底色采样为 RGB(110,186,255)，普通文字为 RGB(160,210,255)。

`16-sent-idle-without-source-marks.png` 与 `17-sent-source-selection.png` 分别记录已发送且刷新后的原文，以及点击消息批注后只显示普通选区的状态。测试同时验证点击别处清除选区、已发送内容保留，以及待发送批注仍可编辑和发送。

## 仍需后续使用验证

真实模型对批注的处理效果取决于模型；本地测试确认发送资料完整。桌面更新后的手工检查另记于本地安装回执。尚未覆盖其他 DSH 版本、不同选区插件同时启用、多个标签页并发编辑同一会话、真实输入法的硬件组合输入，以及超长历史的自动加载定位。

这不是对 Codex 全部行为一致性的声明。实现以用户截图中的选区菜单、可选评论浮层、蓝色编号和发送入口为基准。
